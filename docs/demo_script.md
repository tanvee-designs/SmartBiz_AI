# SmartBiz AI — Live Demo Script

## ১. Introduction (১ মিনিট)
- আমাদের প্রজেক্ট "SmartBiz AI" একটি বিজনেস অটোমেশন সিস্টেম।
- এর মূল উদ্দেশ্য: ম্যানুয়াল কাজ কমানো, লিড ম্যানেজমেন্ট, অটোমেটেড ইমেইল এবং AI রিপোর্ট।

## ২. Lead Collection (২ মিনিট)
- ড্যাশবোর্ডে গিয়ে "Leads" ট্যাবে ক্লিক করব।
- ফর্মে নতুন কাস্টমারের ডেটা (নাম, ইমেইল, ফোন) দিয়ে সেভ করব।
- দেখাব ডাটাবেসে ডেটা সেভ হয়েছে এবং ড্যাশবোর্ডে লিস্টে দেখা যাচ্ছে।
- (ঐচ্ছিক) ডুপ্লিকেট ইমেইল দিয়ে দেখাব কীভাবে 409 Conflict আসে।

## ৩. n8n Automation (২ মিনিট)
- n8n ড্যাশবোর্ডে যাব।
- দেখাব কীভাবে নতুন লিড আসার সাথে সাথে n8n ওয়ার্কফ্লো ট্রিগার হচ্ছে।
- Gmail নোড থেকে অটোমেটেড ইমেইল যাচ্ছে এবং Google Sheets-এ ডেটা সেভ হচ্ছে।

## ৪. AI Reports (২ মিনিট)
- ড্যাশবোর্ডের "AI Reports" ট্যাবে যাব।
- Member 3-এর Gemini API দিয়ে জেনারেট করা রিপোর্ট দেখাব (summary, insights, recommendations)।

## ৫. System Architecture (১ মিনিট)
- `docs/architecture.md` ফাইলে থাকা ডায়াগ্রামটা দেখাব।
- ফুল ফ্লো ব্যাখ্যা করব: Frontend -> Backend (FastAPI) -> Database (SQLite) -> n8n -> Gemini AI।
